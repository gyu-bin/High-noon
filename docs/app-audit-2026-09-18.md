# High Noon — portrait / whole-app implementation audit

## Scope and approval boundary

Latest direction: the entire app stays upright in portrait. Cinematic Western town,
readable characters, dark wood/leather controls and warm cream/gold typography are
the visual reference. The older landscape requirement is superseded. Existing
character identities, progress, unlock rules and gameplay timing are preserved.

This is an implementation and static/build audit, **not a device visual approval**.
Native UI automation was unavailable: the required computer-use skill could not
find the Orca CLI. No substitute UI-control workflow was used. No app was published,
no OTA was sent, no purchases were made, and no user progress was reset.

## Changes in this audit

| Area | Finding / change |
| --- | --- |
| Local character selection | Replaced the old small sprite grid with a large character stage, P1/P2 selection slots, previous/next controls and a 26-character thumbnail roster. Round selection and starting a duel are now separate actions. |
| Local match result | Explicit rematch and character-selection buttons replace the whole-screen exit target; content scrolls on small screens. Rematch resets scores, hearts, round bookkeeping and pending effects. |
| Local arena | Fit each character to its half-screen; align portrait halves consistently and use cinematic signal boards. P2 remains upside-down at the top for face-to-face play. |
| Character rendering | All player/NPC pose registries now use the 130 high-resolution true-alpha clarity assets. Removed obsolete image references, not source files. Selection thumbnails use static images, avoiding unnecessary five-layer animations. |
| Defeat animation | Already-collapsing HIT/DOWN artwork no longer receives the old large rotation/drop on top. Delayed pose crossfades and motion values cancel on cleanup. |
| Gunfire | Local duel muzzle flash is a short one-shot asset effect, not a permanently repeating pulse. Corrected the effect side for the new fire poses. |
| Interruptions | Both duel modes pause on app background/inactive transitions. Repeated pause requests are idempotent so reaction times exclude the entire interruption. |
| Timers | Local impact/heart sounds are tracked and cancelled when leaving the duel. Animation cleanup added to dust and pose effects. |
| Menu/title | Removed obsolete rotate-to-landscape prompt; adjusted menu title sizing. Title entry does not wait on audio/haptics and guards repeated taps. |
| Small screens | Character selection scrolls; local setup and match results also scroll. |
| Portrait safety | Native modal orientation masks are portrait-only, complementing the existing app/root/game/native portrait locks. |
| iOS tooling | Podfile post-install raises old dependency resource-bundle deployment targets to the app minimum, while preserving higher dependency minimums. This addresses Xcode 27 rejecting iOS 9–13 pod targets. |

## Device verification still required

1. Cold launch on both platforms: splash seam, no white flash, correct title entry.
2. Every menu, selection and modal remains portrait when physically rotating.
3. P1 and P2 can select all 26 characters; selected identity persists into battle.
4. Check 320/375-point small displays and large phones for clipping/scroll reachability.
5. Native multitouch: simultaneous taps, either player early, either player wins.
6. HIT → DOWN stays visible before round results in both modes; no persistent muzzle flash.
7. Lock screen / call interruption in READY, STEADY and BANG, then explicit resume.
8. Final match → rematch and final match → selection reset correctly.
9. NPC special abilities, ad revive, purchase restoration and progress backup need
   their normal device/sandbox integration tests; they were not exercised here.

Known remaining polish: some statistics/settings copy is still Korean-only even
when a different language is selected. Full visual parity with the concept sheet
cannot be certified without the native screen pass above.
